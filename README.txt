دعوة زفاف جاهزة لـ GitHub Pages
1) ارفع index.html ومجلد assets كما هما إلى جذر مستودع GitHub.
2) ضع الأغنية باسم song.mp3 داخل assets (ملف MP3 من اختيارك).
3) ضع صورك داخل assets/photos بالأسماء photo1.jpg إلى photo4.jpg، أو عدّل أسماء الصور في index.html.
4) من Settings > Pages اختر Deploy from a branch ثم main و /(root) واحفظ.
الأسماء والتاريخ والقاعة أمثلة قابلة للتعديل مباشرة داخل index.html.
ملاحظة: المتصفح يسمح ببدء الصوت بعد نقرة المستخدم؛ لذلك يبدأ عند الضغط على الظرف. يلزم إضافة ملف الأغنية الخاص بك.
